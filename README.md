# Real Estate Portfolio Performance & Risk Dashboard

Synthetic portfolio analytics project for a private equity real estate portfolio focused on manufactured housing and self-storage.

## Structure

- `data/` generated CSV data files
- `sql/` SQL scripts (to be added in later phases)
- `excel/` Excel workbook outputs (to be added in later phases)
- `docs/` project documentation (to be added in later phases)
- `generate_data.py` synthetic dataset generator

## Generate Data

```bash
python3 generate_data.py
```
